tecnologias a ser aplicadas:
Java, MySQL e UI/UX design
-
Projeto sendo desenvolvido por:
Anderson S
-
Objetivo do Software:
Sistema para gerenciar contas, senhas e logins com inúmeras contas salvas internamente e remotamente com sincronização em nuvem, com opção para anotações e tags em cada login salvo, principalmente na segurança das contas e credencias, manter as senhas em um local seguro no dispositivo e na nuvem, visando que o usuário possa usar recursos do sistema como copiar as senhas de forma rápida e manter um cofre pessoal para cada usuário.
-
Requisitos do sistema:
Disponível em: PC e Mobile(futuramente)
500 GB SSD
4GB Ram (Ainda em analise)
Processador Intel core I3 - 4170 (Ainda em analise)
Sistema baseado em 32/64 Bits
